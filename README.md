# 🏭 Industrial Asset Maintenance Analytics

## Overview

Industrial Asset Maintenance Analytics is a business-focused Data Analytics project designed to analyze industrial asset performance, maintenance costs, downtime, failures, and operational efficiency.

The project uses **Excel and SQL** to transform maintenance data into meaningful business insights and management-level reporting.

---

## 🎯 Business Objective

The objective of this project is to help maintenance teams and management understand:

- Asset performance
- Maintenance expenditure
- Machine downtime
- Asset status
- Failure patterns
- Technician workload
- Maintenance type distribution
- Plant and department performance

---

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- SQL
- Pivot Tables
- Charts & Dashboards
- Data Analysis

# 📌 Key Metrics

The analysis includes:

- Total Assets
- Active Assets
- Assets Under Maintenance
- Total Downtime Hours
- Total Maintenance Cost
- Average Repair Time
- Active Asset Rate
- Average Asset Age

---

# 📈 Key Analysis Areas

### Asset Performance
Analysis of asset status and asset age distribution.

### Maintenance Cost
Maintenance expenditure analyzed across plants and departments.

### Downtime
Machine downtime analyzed by machine type and operational areas.

### Failure Analysis
Identification of frequently occurring machine failure types.

### Technician Analysis
Analysis of technician workload and work orders.

### Maintenance Type
Comparison of:

- Preventive Maintenance
- Corrective Maintenance
- Predictive Maintenance

---

# 💡 Business Value

The analysis helps maintenance teams:

- Identify high-cost plants
- Detect high-downtime machines
- Understand asset utilization
- Identify common failure types
- Monitor maintenance workload
- Prioritize maintenance activities
- Support asset replacement decisions
